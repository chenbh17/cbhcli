# v5.1.3 更新日志

## 核心功能：模型配置新增 thinking 与 reasoning_effort 参数

为模型配置新增 **`thinking`**（思考模式开关）和 **`reasoning_effort`**（推理强度）两个可选参数，CLI 与 Web 界面同步支持。

### 功能说明

| 参数 | 类型 | 取值 | 说明 |
|------|------|------|------|
| `thinking` | 布尔 | `true` / `false` | 思考模式开关（如 DeepSeek 等模型的 thinking 参数） |
| `reasoning_effort` | 字符串 | `low` / `medium` / `high` | 推理强度（如 OpenAI o 系列模型的 reasoning_effort 参数） |

**默认行为**：
- 新添加的模型默认**不配置**这两个参数（即 `None`）
- 参数为 `None` 时**不传给 API**，完全不影响现有模型和请求行为
- 配置后可随时通过 `/model config` 修改或清除（输入 `none` 清除，恢复不传）

### CLI 端（/model 命令）

- **`/model add`** 添加模型时新增两个交互提示：
  - `thinking 参数 (on/off 或 true/false，留空不传)` — 输入 on/true/1/yes/y → `true`，off/false/0/no/n → `false`
  - `reasoning_effort 参数 (如 low/medium/high，留空不传)` — 原样存储，输入 `none` 视为不传
- **`/model config`** 修改模型时新增两个可配置项：
  - `thinking 参数 (当前: ..., on/off 或 true/false, 输入 none 清除)`
  - `reasoning_effort 参数 (当前: ..., 如 low/medium/high, 输入 none 清除)`
- **`/model list`** 与 **`/model info`** 显示当前配置值（未配置显示"不传该参数"）

### Web 端

- **模型添加/编辑弹窗**（`showModelForm`）新增两个字段：
  - `thinking` — 下拉选择：不传 / 开启 (true) / 关闭 (false)
  - `reasoning_effort` — 输入框，placeholder 提示 `low / medium / high`，留空不传
- **模型卡片**显示标签：`thinking:true` / `effort:medium`（未配置不显示）
- **后端 `ModelConfig`**（Pydantic）新增字段：`thinking: Optional[bool] = None`、`reasoning_effort: Optional[str] = None`
- 编辑模型时通过 `to_config_dict()` 的 `exclude_none=True` 自动剔除 None 字段，不覆盖已有配置

### 请求透传逻辑（core/model.py）

`LLMClient` 新增 `_get_extra_payload()` 方法，`chat()` / `chat_stream()` 组装 payload 时按条件附加：

```python
def _get_extra_payload(self) -> dict:
    """获取思考相关参数（None 不传给 API）"""
    extra = {}
    if self.thinking is not None:
        extra["thinking"] = self.thinking
    if self.reasoning_effort is not None:
        extra["reasoning_effort"] = self.reasoning_effort
    return extra
```

- 两个参数均为 `None` 时，payload 与旧版本**完全一致**，零影响
- 参数为 `false` / `"low"` 等非 None 值时按配置原样传递
- 由于 `LLMClient` 所有实例化点（CLI app/ai_handler、Web server、子 Agent、Agent 链条、fallback 切换）均直接接收完整 model_config 字典，新字段自动生效，**无需修改任何调用方**
