# v5.0.2 更新日志 — Web 端长期记忆（memory.md）未注入系统提示修复

## 概述

v5.0.2 修复 Web 界面系统提示词缺少长期记忆（memory.md）的 bug。CLI 端正常，Web 端从未注入 memory.md，导致 AI 在 Web 界面无法看到用户要求记住的长期记忆内容。本版本仅修改 `web/server.py` 一个文件（+28 行），CLI 零影响。

---

## 1. Web 端长期记忆未注入系统提示修复

**修改文件**：`web/server.py`

### 问题

Web 界面中，AI 的系统提示词缺少 `## 长期记忆` 段落。用户在 memory.md 中记录的所有长期记忆，CLI 端能正常识别，Web 端完全看不到。

### 根因

`WebChatSession._rebuild_system_prompt()` 调用 `AgentPersona.build_system_prompt()` 时**漏传 `memory_content` 参数**。

虽然 `AgentManager.load_agent_persona()` 会读取 memory.md 到 `persona.memory` 属性，但 `build_system_prompt()`（`core/agent.py`）只使用 **`memory_content` 参数**，不使用 `self.memory` 属性——`persona.memory` 被加载后从未被使用，长期记忆"静默丢失"。

CLI 端（`core/app.py` 的 `_reset_session` / `_update_system_prompt`）通过 `_load_memory_md()` 读取 memory.md 并显式传入，所以 CLI 正常：

```python
# CLI app.py（正常）——读取 memory.md 并传入
memory_content = self._load_memory_md()
system_prompt = self.current_persona.build_system_prompt(
    agent_name=...,
    model_name=...,
    memory_content=memory_content,      # ← CLI 传了这个参数
    ...
)

# Web server.py（修复前，bug）——没传 memory_content
system_prompt = persona.build_system_prompt(
    agent_name=self.agent_name,
    model_name=self.model_name,
    active_skills_prompt=active_skills_prompt,
    cwd=os.getcwd(),
    supports_vision=getattr(self.llm_client, "supports_vision", False),
)                                       # ← 缺 memory_content
```

### 修复

复刻 CLI 逻辑，两处修改：

**① `WebChatSession` 新增 `_load_memory_md()` 方法**（复刻 CLI `app.py` 同名方法）：

读取 memory.md，跳过 `---` 之前的模板说明部分（`# 对话记录` 标题和使用说明），只保留实际记忆内容：

```python
def _load_memory_md(self) -> str:
    """读取 memory.md 文件内容（复刻 CLI app.py _load_memory_md 逻辑）。

    跳过模板说明部分（--- 之前），只保留实际记忆内容。
    """
    if not self.agent_config:
        return ""
    memory_file = self.agent_config.workspace_path / "memory.md"
    if memory_file.exists():
        try:
            content = memory_file.read_text(encoding='utf-8')
            lines = content.split('\n')
            in_content = False
            content_lines = []
            for line in lines:
                if line.strip() == '---':
                    in_content = True
                    continue
                if in_content:
                    content_lines.append(line)
            return '\n'.join(content_lines).strip()
        except Exception:
            pass
    return ""
```

**② `_rebuild_system_prompt()` 中读取并传入**：

```python
# 读取长期记忆（与 CLI 一致，memory.md 始终包含在系统提示中）
memory_content = self._load_memory_md()
system_prompt = persona.build_system_prompt(
    agent_name=self.agent_name,
    model_name=self.model_name,
    memory_content=memory_content,              # ← 新增
    active_skills_prompt=active_skills_prompt,
    cwd=os.getcwd(),
    supports_vision=getattr(self.llm_client, "supports_vision", False),
)
```
