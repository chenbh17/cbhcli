# v5.2.0 更新日志

## Web 界面 AI 回复支持 Mermaid / ECharts 图表渲染

### 需求
AI 回复中的 ` ```mermaid ` 流程图 / 时序图代码块与 ` ```echarts ` 图表配置代码块，此前只能显示为原始代码文本，现在渲染为可视化图表（SVG / 交互式图表）。

### 方案
- **Mermaid 11.16.1**：渲染 ` ```mermaid ` 代码块为 SVG（流程图、时序图、类图、甘特图等）。
- **ECharts 6.1.0**：渲染 ` ```echarts ` 代码块为交互式图表（代码块内容是 ECharts `option` 配置）。
- **纯前端离线渲染，零新增 Python 依赖**：两个库的 `.min.js` 作为静态资源打进 wheel（`web/static/vendor/`），由已有 `StaticFiles` 挂载提供，不走 CDN，任何电脑 `pip install` 后浏览器即可渲染、无需联网。

### 关键设计
1. **渲染时机 = 回复完成后**（而非流式中）：Web 与 CLI 一致，流式过程是「每个 chunk 到达就 `innerHTML = renderMd(全部累积文本)` 全量重渲染」。KaTeX 同步轻量可内联；但 mermaid 渲染是异步、echarts 要 `init` 实例，若跟随每个 chunk 重渲染会剧烈闪烁 + 实例泄漏。因此**流式中 mermaid/echarts 代码块按代码显示，回复完成（`done`/`finally`）或恢复历史时再一次性后处理渲染**。
2. **懒加载**：mermaid.min.js 3.5MB + echarts.min.js 1.1MB 较大，不放进 `index.html` 同步加载；`renderDiagrams` 检测到图表块才用 `loadDiagLib` 动态注入 `<script>`（Promise 缓存防重复），`?v=` 版本号从已加载的 `app.js` 推导保证缓存失效一致。首屏不受影响。
3. **echarts option 解析**：`JSON.parse` 优先，失败则 `new Function("return ("+src+")")()` 求值兜底（支持函数 / 尾逗号等完整 ECharts 语法）。内容为 AI 本地生成，风险低。
4. **安全**：mermaid `securityLevel:"strict"`（内置 DOMPurify 消毒防 XSS）；echarts 用内置 `dark` 主题。
5. **失败回退**：mermaid 渲染异常 / echarts option 解析失败时保留原代码块，不报错变红（与 KaTeX `throwOnError:false` 一致）。
6. **自适应**：echarts 容器用 `ResizeObserver` 监听尺寸变化自动 `resize()`。

### 改动
1. **新增静态资源**：`web/static/vendor/mermaid/mermaid.min.js`（3.5MB）、`web/static/vendor/echarts/echarts.min.js`（1.1MB）。靠已有 `[tool.setuptools.package-data] "cbhcli_pkg.web" = ["static/**/*"]` 打进 wheel。
2. **`js/app.js`**：新增 `_staticVer` / `loadDiagLib`（懒加载）/ `ensureMermaidInit` / `parseEchartsOption` / `renderDiagrams`；三处挂钩——流式完成 `finally` 块（`renderDiagrams(aiBody)`）、`renderRestoredMessages`（历史恢复，`renderDiagrams(col)`）、`showHistoryDetail`（历史详情弹窗，`renderDiagrams(body)`）。
3. **`css/style.css`**：`.cbh-diagram` / `.cbh-mermaid`（居中 + svg 自适应）/ `.cbh-echarts`（高 360px）深色主题样式。
4. **`index.html`**：无需加 script 标签（懒加载），仅 `?v=` 缓存参数随版本更新。

### 范围界定
- 只渲染 ` ```mermaid ` 与 ` ```echarts ` 两种语言标记的代码块；其余代码块不受影响。
- 流式过程中显示为代码（带语法高亮 + 复制按钮），完成后替换为图表。
- 渲染发生在：本轮回复完成、刷新恢复历史消息、查看历史会话详情三处。

### 验证
Web 界面发送含 ` ```mermaid ` 流程图与 ` ```echarts ` 折线图的消息：回复完成后代码块原地替换为 SVG / 交互式图表；刷新恢复历史、查看历史详情同样渲染；语法错误的 mermaid 保留代码块不报错。
