## 一、症状（用户截图反馈）

欢迎面板行拖选 `v5.5.3` 后高亮"重复 + 错位"——行尾多出一块白色
高亮（落在行尾补白空格上），选中内容本身的高亮也不干净；**Ctrl+C 复制的
内容却完全正确**（"复制对、显示错"）。

## 二、根因

`_main_fragments` 对每个样式片段调用 `_split_select(text, style, c0, c1)`
时传的是**整行**显示列范围，而 `_split_select` 内部 `col` 从 0 起算（只接受
片段局部列范围）→ 选区从**每个片段开头**重新套用一遍：
- 行尾补白空格 run 的前 N 列被 reverse → 行尾白色高亮块（截图症状）；
- 行内多个样式 run 时每个 run 开头各高亮一段 → 重复/错位。

复制路径 `_extract_cols` 的 `col` 在片段循环**外**初始化、跨片段累计，故复制
正确。旧门禁 `check_selection` 只用单样式片段纯文本行（`SEL-LINE-xx`），
从未暴露多片段场景。

## 三、修复（`core/ui/shell.py`）

1. 新抽 `_highlight_line(line, c0, c1)`：逐片段累计列偏移 `base`，换算局部
   坐标 `(c0-base, c1-base)` 再传 `_split_select`；片段完全在选区外原样保留
   （不产生空 reverse 片段）；`c0=None` 透传。宽字符不拆/组合符跟随语义不变。
2. `_main_fragments` 的逐片段循环改调 `_highlight_line`（整行范围语义收口
   到单一函数，杜绝再犯）。

**通用规则**：按列拆分多样式片段行时，列偏移必须跨片段累计；"整行范围"与
"片段局部范围"语义不能混传。

## 四、测试

- 新增门禁 `tests/ui/check_selection_highlight.py`（第 31 套件）：
  - 单元：多片段列偏移累计、CJK 宽字符不拆、**补白不高亮**、选区外片段原样、
    无选区透传；并含"旧逻辑直传整行范围必高亮补白"的对照断言（证明 bug 存在过）。
  - pty 集成：子进程打印欢迎面板同构行（dim 文本 run + 默认样式补白 run），
    拖选后 **pyte 列精确重放**断言 reverse 格恰好落在选区列、相邻行无 reverse、
    跨行选区首行含补白到行尾/末行部分列、两次 Ctrl+C 复制内容正确。
- ⚠️ 门禁开发踩坑：`pyte.Screen` 参数序是 **(columns, rows)**——误写
  `(24, 80)` 得到 24 列宽屏幕，第 24 列起折行把补白空格折到下一行，表象极像
  "pyte 丢空格 reverse 属性"（一度误判为产品/重放库 bug）；隔离实验逐段 feed
  定位到参数序后纠正。**教训：重放断言异常先怀疑重放台配置，再怀疑产品。**
- `check_selection.py` 回归绿；`tests/ui/` **31 套件全绿**。
