# CBHCLI v4.9.8 更新日志 — CLI 状态栏标题调亮 / Web 快捷弹窗加 MCP 开关 / Web 切换模型保留会话

> 三个体验修复：① CLI 输入框下方状态栏的项目标题（模型/上下文/Agent/技能/路径）改为亮白加粗，与彩色值形成对比；② Web 聊天页右上角「🔧 工具开关」快捷弹窗新增 MCP 工具启停区；③ Web 切换模型改为原地切换（对齐 CLI `/model use` → `switch_model`），会话及上下文完整保留。

## 一、CLI 状态栏标题调亮（含 prompt_toolkit HTML class 失效根因修复）

**文件**: `cbhcli_pkg/core/input_box.py`

### 根因（重要踩坑）

原实现用 `HTML('<style class="bottom-toolbar.model">...')` 为状态栏片段着色，但 **prompt_toolkit 的 HTML 解析器会丢弃 `<style>` 标签的 `class` 属性**（`html.py` 中 `"style"` 被排除在 name_stack 之外，仅解析 `fg/bg/color` 属性）——class 从未生效，整个状态栏实际上一直是默认灰色，各项目配色（青/黄/粉/绿/蓝）从未真正显示过。

### 修复

- `_build_toolbar()` 与 `prompt()` 改用 **`(style, text)` 元组列表**显式指定 class（如 `("class:bottom-toolbar.label", "模型: ")`），样式正常解析。
- 新增样式类 `bottom-toolbar.label`: `bold #ffffff bg:#1c1e24`（亮白加粗）。
- 标签（模型/上下文/Agent/技能/路径）亮白加粗，值保留原有配色，层次清晰；`❯` 提示符的青色加粗（`class:prompt`）也一并修复。

## 二、Web 快捷弹窗新增 MCP 工具开关

**文件**: `cbhcli_pkg/web/static/js/app.js`（`showQuickTools()`）

- 聊天页右上角 🔧 弹窗在内置工具/cbhpacks 分组之后，新增「🔌 MCP 工具」区块：
  - 每个 MCP 服务器显示名称、连接状态灯（绿/红）、工具数、URL；
  - 并行拉取各服务器完整工具列表（`GET /api/agents/{a}/mcp/{s}/tools`，含禁用状态）；
  - 每个工具带开关，切换调用既有 `PUT .../tools/{t}` 接口，与 MCP 管理页行为一致；
  - 无服务器时显示引导提示；未连接/加载失败有降级提示。

## 三、Web 切换模型保留会话及上下文

**文件**: `cbhcli_pkg/web/server.py` + `cbhcli_pkg/web/static/js/app.js`

### 问题

旧版 Web 切换模型仅调用 `POST /api/models/{m}/select` 更新 `last_selected_model`，前端随后 `clearMessages() + restoreMessages()` —— 由于会话按 `(agent, model)` 键存储，新键下无会话，当前对话上下文全部丢失，与 CLI `/model use` 原地切换（v4.9.6）行为不一致。

### 修复

**后端新增 `POST /api/chat/switch_model`**，对齐 CLI `CBHCLIApp.switch_model()`：

1. 校验新模型存在并更新 `last_selected_model`；
2. 查找旧键 `(agent, old_model)` 下的活跃会话；无会话时仅更新选择返回；
3. 新键位若已有遗留会话：自动保存到 history 后让位（与 `chat/load` 一致）；
4. **原地替换模型组件**（会话消息一条不动）：
   - `llm_client = LLMClient(model_config)`
   - `token_counter = get_token_counter(model)`
   - `context_compressor = ContextCompressor(...)`
   - `context_window.model_limit = llm_client.context_limit`
   - `app_proxy.llm_client / token_counter / context_compressor` 同步
5. 更新 `model_name / session_key`，`_rebuild_system_prompt()` 原地更新首条 system 消息（模型名、视觉能力描述随模型变化）；
6. 会话键迁移 `(agent, old)` → `(agent, new)`，返回最新 usage。

**前端三处切换入口全部改走新端点**：聊天页模型下拉（`onModelChange`）、🧠 快捷弹窗（`showQuickModel`）、模型管理页「使用」按钮。切换成功后不再清空/重拉消息（DOM 与会话内容一致），仅 `refreshStatus()` 刷新上下文用量条（新模型限额可能不同）；失败时回滚选中态。

### 验证

- 消息/上下文保留、键迁移、遗留会话让位并存入历史、无会话/模型不存在/缺参数/同模型四种边界，全部通过；
- `cbhcli --version` = 4.9.8，Web 静态服务与端点冒烟测试通过。
