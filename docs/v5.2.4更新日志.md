# CBHCLI v5.2.4 更新日志

**日期**: 2026-08-14
**主题**: 压缩摘要请求兼容性修复——thinking.type=disabled 部分模型不支持导致压缩 400

## 问题现象

用户执行上下文压缩（自动/手动 `/comp`）时失败：

```
❌ 压缩失败: API请求失败: 400 - {"error":{"code":"InvalidParameter","message":"thinking.type `disabled` is not supported by this model Request id: 0217869543759517424dba2bd6e77b99d402060a9cf8c0f8e2999","param":"","type":"BadRequest"}}
```

## 根因

v5.2.3 为修复"思考模型摘要失败"（思考 token 耗尽摘要 max_tokens 预算），在
`ContextCompressor._generate_summary` 中对配置了 thinking 的模型显式传：

```python
if getattr(self.llm_client, "thinking", None) is not None:
    kwargs["thinking"] = {"type": "disabled"}
```

该写法对 DeepSeek 有效（支持 ThinkingOptions 结构体），但**部分 API 不支持
`thinking.type=disabled` 参数**（如智谱 GLM，从报错 Request id 格式判断），
直接 400 `InvalidParameter`，导致这些模型上压缩系统性失败。

## 修复方案（按用户决策：摘要请求完全不传 thinking/reasoning_effort）

### 1. `core/model.py`：chat()/chat_stream() 新增 skip_thinking 哨兵参数

```python
skip_thinking = kwargs.pop("skip_thinking", False)   # 先 pop 防混入 payload
payload = {..., **self._get_extra_payload(), **kwargs}
if skip_thinking:
    payload.pop("thinking", None)
    payload.pop("reasoning_effort", None)
```

- 无论模型配置了什么 thinking/reasoning_effort，调用方传 `skip_thinking=True`
  即可让本次请求完全不携带这两个参数（对所有 API 最兼容）；
- 哨兵先从 kwargs pop 出，不会混入 payload；
- v5.2.3 的显式 `thinking={"type":"disabled"}` 覆盖路径保留（回归兼容，
  检测到 disabled 时仍自动移除冲突的 reasoning_effort）；
- chat() 与 chat_stream() 两处同步实现。

### 2. `context/compressor.py`：摘要请求改传 skip_thinking

```python
kwargs = {"temperature": 0.3, "max_tokens": max_tokens,
          "skip_thinking": True}
```

删除原 `thinking={"type":"disabled"}` 注入逻辑。

**已知副作用（可接受降级）**：默认开思考的模型（如 DeepSeek 不传 thinking
时默认开启）思考 token 计入摘要 max_tokens 预算，若思考耗尽预算导致
content 为空，由 v5.2.3 的 `MIN_SUMMARY_CHARS` 空摘要检查拒绝压缩
（保真不污染上下文），不会造成静默失忆。

## 验证（26/26 通过，mock HTTP 层捕获实际 payload）

| 类别 | 验证项 |
|------|--------|
| 回归 | 普通对话请求 thinking(enabled)/reasoning_effort(high) 照常附加 |
| 新逻辑 | chat(skip_thinking=True) 后 payload 无 thinking/reasoning_effort，哨兵不混入，模型配置 max_tokens=32000 仍生效 |
| 优先级 | skip_thinking + 显式 max_tokens=2048，kwargs 优先于模型配置 |
| 兼容 | 显式 thinking=disabled 旧路径：reasoning_effort 仍被移除 |
| 流式 | chat_stream(skip_thinking=True) 同样剔除，stream=True 保留 |
| 端到端 | _generate_summary 实际 payload 无 thinking/reasoning_effort，max_tokens 封顶、temperature=0.3 正常 |
| 压缩全流程 | compress() 成功，保留最早 2 轮 + 最近 3 轮，中间摘要替代，摘要消息恰 1 条 |
