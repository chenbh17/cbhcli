# v5.1.9 更新日志

## Web 界面 AI 回复支持 LaTeX 公式渲染（KaTeX）

### 需求
cbhcli-jupyter 插件（v0.2.12）已支持 AI 回复里的 LaTeX 公式渲染，本次把**相同逻辑复现到 cbhcli Web 界面**：AI 回复中的 `$...$` / `$$...$$` 等公式此前显示为原始文本，现在用 KaTeX 美观渲染。

### 方案
集成 **KaTeX 0.18**，采用**静态文件离线引入**（Web 界面是原生 JS、无构建，不能 npm import；也不用 CDN，保证内网离线可用）。

### 改动
1. **新增静态资源** `cbhcli_pkg/web/static/vendor/katex/`：
   - `katex.min.js`（271KB）、`katex.min.css`（24KB）、`fonts/`（60 个字体：woff2/woff/ttf）。
   - 由 `app.mount("/", StaticFiles(static))` 以 `/vendor/katex/...` 路径提供。
2. **`index.html`**：head 增加 `katex.min.css` 样式引用，底部在 `app.js` 之前加载 `katex.min.js`；三处静态资源 `?v=` 缓存参数随版本更新。
3. **`js/app.js`**：`renderMd` 集成 KaTeX——新增 `extractMath`（单遍扫描，按优先级「围栏代码块 > 行内代码 > `$$…$$`/`\[…\]` 块级 > `$…$`/`\(…\)` 行内」把公式抽成占位符，**保护代码块内的 `$` 不被误判**）与 `renderTex`（`katex.renderToString`，`throwOnError:false` 容错）；marked 渲染后把占位符还原为块级 `.cbh-math-block` / 行内 `.cbh-math-inline`。
4. **`css/style.css`**：深色主题公式样式（用主题变量，块级居中 + 溢出横向滚动、行内/块级字号）。

### 范围界定（与 jupyter 插件一致）
- 只渲染**正文里的公式**：`$…$`/`\(…\)` 行内、`$$…$$`/`\[…\]` 块级。
- **所有代码块（含 ` ```latex `/` ```math `/` ```tex `）与行内代码一律保护为代码、不渲染公式**——代码块内 `$` 原样保留。
- 不渲染完整 LaTeX 文档结构（表格/图片/TikZ/列表/定理等）：KaTeX 是数学渲染器，这些客户端无法可靠渲染，故代码块保护模式最稳。

### 版本
`5.1.8 → 5.1.9`（7 处：`__init__.py`×2、`pyproject.toml`、`mcp_client.py`、`server.py`、`README.md`、`index.html` 的 `?v=` 参数）。

### 验证
Web 界面发送含公式消息：行内 `$E=mc^2$`、块级 `$$\int_0^1 x^2 dx$$` 正确渲染为 KaTeX（字体加载），代码块内 `$` 不被误渲染。
