# CBHCLI v5.2.8 更新日志

> 发布日期: 2026-08-23
> 主题: Web 界面四项修复 + 侧边栏全面重构（工作区会话管理）
> + 会话管理菜单（重命名/复制/删除）+ 会话切换不再产生副本

---

## 一、Web 界面四项修复

### 1.1 Todo 面板每次调用都展示
旧版流式渲染中 Todo 面板原地替换（`replaceWith`），整个对话只显示最新一份，
表现为"只有最开始/最后调用时才显示"。现改为**每调用一次 Todo 追加渲染一个
面板**，与恢复历史会话的渲染逻辑一致。

### 1.2 模型调用失败显示详细报错
旧版主模型失败切换备用模型时，SSE `fallback` 事件只发"主模型调用失败，
切换到备用模型…"，不含原因。现携带详细报错（与 CLI 的
`⚠️ 主模型调用失败: {primary_error}` 对齐）。

### 1.3 工具卡片默认收起
旧版工具卡片创建即展开（`tool-card open`），页面被撑得很长。现默认收起，
仅以下情况展开：需要用户确认（便于审查参数）、执行失败、AI 发送文件/图片。
点击标题仍可手动展开/收起。

### 1.4 工具确认按钮与 CLI 对齐
顺序改为 CLI 的 `[Y/n/all/always]`：✓ 允许 / ✕ 拒绝 / 全部允许 /
**始终允许该命令**（原"始终允许"改名，消除与"全部允许"的歧义——
前者=提炼永久 allow 规则，后者=本会话内不再确认）。

## 二、侧边栏重构：工作区会话管理

### 2.1 设置按钮收口
左侧栏原有的 13 个导航按钮（Agent/链条/模型/备用模型/技能/MCP/知识库/
工具/安全/索引/历史/设置等）统一收归**左下角一个 ⚙️ 设置按钮**，点击跳转
设置页；设置页顶部新增"管理功能"导航卡片墙，可进入全部原配置视图。

### 2.2 工作区会话列表（参考移动端截图设计）
- 顶部"⊕ 新会话"按钮；"工作区"标题栏带搜索/刷新/打开文件夹三个图标按钮
- 会话按**工作空间文件夹**分组：文件夹可下拉/收回，组内为该工作空间下的
  会话（标题 + 相对时间），默认显示 5 条 + "展开其余 N 个会话"
- **打开工作空间**：文件夹选择弹窗（面包屑 + 子目录浏览，限定服务器当前
  目录内），打开后服务器 `chdir` 切换工作目录，Agent 系统提示同步重建
  （Agent 知道当前打开的工作空间），当前会话自动保存到旧工作空间
- 点击历史会话即恢复该会话并切换到其所属工作空间
- 会话保存逻辑与历史会话完全一致（每轮自动保存、/new 保存），仅新增
  `workspace` 字段用于分组；`session_history.py` 的 save/list 同步扩展

### 2.3 新增后端 API
- `GET  /api/workspace/info?agent_name=` 工作空间+会话分组列表（含活跃会话）
- `GET  /api/workspace/browse?path=` 子目录浏览（限定服务器根目录内）
- `POST /api/workspace/open` 打开工作空间（保存旧会话 + chdir + 刷新提示）
- `POST /api/chat/load` 新增可选 `workspace` 参数，恢复会话时同步切换工作空间
- `GET  /api/chat/status` 返回 `workspace` 字段

## 三、会话管理菜单（三点按钮）

侧边栏会话条目鼠标悬停时右侧显示「⋯」三点按钮（暂时隐藏时间标签让位），
点击弹出管理菜单：

- **✏️ 重命名**：修改会话标题（活跃会话记入 `custom_title`，历史会话改写文件
  title 字段；自动保存不会覆盖重命名后的标题）
- **📄 复制会话**：以新 id 创建独立副本（可分支对话），标题保持一致
- **🗑 删除会话**：确认后删除历史文件；若删除的是活跃会话，同时清除内存对话
  并清空聊天视图

新增后端 API：
- `POST /api/workspace/session/rename`
- `POST /api/workspace/session/delete`
- `POST /api/workspace/session/copy`

`session_history.py` 新增 `update_session_title()` / `load_session_full()`，
`save_session()` 新增 `title` 参数（标题优先级: 显式传入 > 已有文件 > 首条消息提取）。

## 四、会话切换不再产生副本（修复"相同会话很多"）

### 4.1 根因
旧版 `chat/load` 每次加载历史会话都 `WebChatSession.create()` 生成**新 session id**，
且切换前先把当前会话另存一次 → 同一对话每点一次就多一个副本文件；
`_set_current_workspace` 还会把所有活跃会话的 workspace 标签改写到新文件夹，
导致"前一个文件夹的会话被带入新文件夹"。

### 4.2 修复
- **加载会话保留原 id/created_at/workspace/title**：后续每轮自动保存幂等覆盖
  同一文件，对该会话的新问答都记录在该会话下（点击会话 = 直接跳转）
- **切换会话不再保存旧会话**（每轮对话本已自动保存落盘），仅中断旧会话
- **`_set_current_workspace` 不再改写其他活跃会话的 workspace 归属标签**
  （只 chdir + 重建系统提示），会话始终归档在创建时的工作空间下
- **打开过的工作空间常驻侧边栏**：旧版工作空间列表只从"当前 + 有会话的"
  推导，打开 A 再打开 B 后 A 消失。现 `~/.cbhcli/web_workspaces.json` 持久化
  最近打开记录（`_set_current_workspace` 时写入），`workspace/info` 合并仍在磁盘
  上的已打开工作空间；排序: 当前 → 最近打开 → 仅历史会话出现的。重启不丢失

## 四点五、文件夹三点管理菜单

会话行有三点菜单后，文件夹行同样悬停显示「⋯」，弹出工作空间管理菜单：

- **📂 选择该文件夹**：切换当前工作空间并**恢复该文件夹下最新会话**
  （`workspace/open` 新增 `resume` 参数；空文件夹则为新会话）——解决
  "多个空文件夹时无法选择某个空文件夹"的问题
- **✚ 新增会话**：切换到该文件夹并开始全新会话（当前文件夹上等同 /new）
- **🗑 删除全部会话**：确认后删除该工作空间下全部历史会话
  （`POST /api/workspace/sessions/clear`），含清除属于它的活跃会话

实现上把 chat_load 的加载逻辑抽为 `_load_session_core()`（保留原 id/时间/
工作空间/标题），chat_load 与 workspace/open resume 共用。

## 四点六、CLI /resume 列表被 Web 会话挤占的修复

现象：Web 端会话与 CLI 共用同一 agent 的 history/ 目录，会话文件多了以后
（实测 480 个）`/resume` 只列最近 20 条，旧的 CLI 会话被挤出窗口"选不上"。

修复：
- 默认列表窗口 20 → **50** 条
- **新增关键词搜索**：`/resume <关键词>` 按标题过滤全部历史（最多扫 500 条），
  超出列表窗口的旧会话也能找回；列表底部附提示
- 用法更新为 `/resume [编号|文件名|关键词]`（同步 cli 帮助/README/
  usage.md 模板 + 全部现有 Agent 的 usage.md）
- **会话标题单行化**：标题取自首条用户消息，含换行时列表折行，行首的
  "1、"/"1." 等内容看起来像重复编号（用户报"好几个编号1"）。现
  `save_session` 提取、`list_sessions` 读取、Web 活跃会话提取、重命名入口
  四处统一把换行/连续空白压缩为单空格，CLI/Web 列表不再折行

## 四点七、服务器重启后会话自动找回（进度条 0% 修复）

现象：Web 服务重启后内存会话清空，浏览器页面仍显示旧对话但后端会话已不存在，
上下文进度条一直 0%；此时继续发消息会开新会话导致可见对话的上下文丢失。

修复（前端自动找回 + 后端按 id 定位）：
- `chat/status` 活跃时返回 `session_id`，前端 `state.currentSessionId` 跟踪
- **页面开着时**：`refreshStatus` 轮询发现 `active:false` 但页面仍有对话内容
  → 按 session_id 自动 `chat/load` 找回原会话（含上下文进度条），并提示
  "检测到服务重启，会话已自动恢复"；恢复失败（会话未落盘）不重试
- **重新打开页面时**：`restoreMessages` 发现无活跃会话 → 自动恢复最近一条
  历史会话（不再空白 + 进度条归零）
- `chat/load` 支持只传 `session_id`（按 `*_{id}.json` 定位文件）
- 用户主动操作（切换/新建/删除会话、切换工作空间）前置空 session_id 标记，
  避免与自动恢复机制竞争

## 四点八、文件管理器 + 双面板布局

新增**文件管理器面板**：展示当前工作空间下的全部文件和文件夹
（后端 `GET /api/files/list`，限定当前工作空间内，目录优先+名称排序，
含大小/修改时间）：

- 点击文件夹进入、面包屑（🏠 根 / 各级目录）+ ⬆ 上级目录按钮导航
- 点击文件**不触发下载**（用户要求：下载只走三点菜单）；
  每行悬停「⋯」三点菜单：文件→📥 下载 / 📋 复制路径；
  文件夹→📂 打开为工作空间 / 📋 复制路径
- 文件类型图标（py/js/图片/压缩包等）

**双面板布局**：工作区面板与文件管理器面板分列主区域两侧：

- 两个面板头部均有 ⇄ 按钮，一键**左右互换**（localStorage 记忆）
- 面板与主区域之间为**拖拽手柄**，鼠标拖动调整面板宽度
  （170~520px，宽度 localStorage 记忆）
- 工作空间切换后文件管理器自动重置到新工作空间根目录；
  对话结束/定时刷新时文件列表自动刷新（Agent 产出的文件即时可见）
