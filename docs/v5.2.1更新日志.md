# v5.2.1 更新日志

## Web 图表渲染修复 + 图片/代码切换（Mermaid / ECharts）

v5.2.0 上线后收到三个问题，本版全部修复并新增切换功能（jupyter 插件 v0.2.14 同步）。

### 问题与根因
1. **echarts 完全不渲染（仍是代码）**：根因是 AI 常把 echarts 配置标成 ` ```json ` / ` ```javascript `（而非 ` ```echarts `），v5.2.0 的选择器只认 `language-echarts`，漏掉了。CDP 实测证实：`echarts` 标签能渲染、`json`/`javascript` 标签不渲染。
2. **jupyter 多个 mermaid 有的渲染有的没渲染**：mermaid 渲染对残留临时元素 / 偶发失败较敏感，需加固。
3. **需求**：渲染后的图右上角要「图片 / 代码」两个按钮切换，代码视图带复制按钮。

### 修复与改动（`js/app.js`）
1. **echarts 标签自动识别**：新增 `collectEchartsBlocks`——显式 `echarts`/`echart` 标签直接渲染；`json`/`javascript`/`js` 标签若内容解析后**含 `series`**（echarts 强特征）也按 echarts 渲染。`parseEchartsOption` 增强：去尾部分号 → `JSON.parse` → `new Function` 求值（支持函数/尾逗号）→ `option = {...}` 赋值形式提取。
2. **mermaid 加固**：新增 `renderMermaidSafe`——渲染前清理残留临时元素（`#id`/`#d{id}`）、失败自动重试一次、成功结果按源码缓存。
3. **图片/代码切换**：新增 `buildDiagramWrap`——每个图表包成 `.cbh-diagram-wrap`，右上角工具栏「图片 / 代码」两按钮；图片视图=SVG/canvas，代码视图=原始源码 + 复制按钮；默认显示图片，点击切换，echarts 切回图片时自动 `chart.resize()`。
4. **`css/style.css`**：`.cbh-diagram-wrap`/`.cbh-diagram-toolbar`/`.cbh-diagram-tab`(active 高亮)/`.cbh-diagram-view` 样式。
