# CBHCLI v5.5.5 更新日志（工具确认界面重构）

> 发布日期：2026-11-23 ｜ 上一版本：v5.5.4
> 本版本内容原为 v5.5.4 同版本迭代（三轮用户反馈），用户明确要求发新版
> v5.5.5 后迁移至此；`docs/v5.5.4更新日志.md` 第七节留指针。

## 一、症状（用户反馈，三轮）

1. **一轮**：CLI 工具执行确认（y/all 那个界面）旧版把全部选项挤在底部
   输入行的一行提示里：`确认执行 terminal? [Y/n/all/always]: `。全屏 TUI
   下这行就是模态输入行本身，紧贴底部状态栏、与主区内容之间没有空行
   分隔，选项含义也无从看到——**不明显**。要求改为按行输出（第一行 y
   后面写明 y 是做什么的）。
2. **二轮**：提示行 `选择 [y/n/all/always]: ` **下方空一行、上方不空行**，
   同时要有**待选择的动画**。
3. **三轮**：下方改**空两行**；提示行改**黄色**。

## 二、定稿布局（全屏 TUI 与 legacy 双模式）

```
确认执行 terminal? 请选择:
  y      本次放行（仅这一次执行）
  n      本次拒绝（不执行该工具）
  all    本会话内不再确认（deny 红线仍拦截）
  always 本次放行，并提炼一条 allow 规则永久生效（写入 permissions.json）
⠋ 选择 [y/n/all/always]: █        ← 模态输入行（黄色 + spinner 待选择动画，上方不空行）
                                  ← 空两行（spacer）
[状态栏]
```

- 选项说明**按行输出到主区**（每行一个选项 + 解释），进入可滚动内容；
- 选项键按 ASCII 宽度 `:<6` 对齐（y/n/all/always 说明列统一），键带颜色
  （y 绿 / n 红 / all 黄 / always 黄），标题加粗；
- 提示行**上方不空行**（紧贴选项块）、**下方空两行**（与状态栏隔开）、
  整行**黄色**（#ffd75f）+ braille **待选择动画**（100ms/帧）；
- 确认语义不变：y/回车=放行、n=拒绝、all=本会话免确认、always=永久规则；
- Web / 链条下游确认走 `_confirm_callback` 分支，**不受影响**。

## 三、实现要点

### 全屏（`core/ui/shell.py`）

- 模态期间 `_main_fragments` 去掉主区末尾待写空行 → 选项块末行（always）
  紧贴模态输入行（上方不空行）；
- `modal_body` 下方加 **2 行 spacer**（下方空两行）；**`_main_height`
  同步扣除 spacer**——否则主区切片按旧高度多算，always 行会被模态行
  盖掉（门禁实测抓出：spacer 1 行时 `_main_height` 未扣 → 末行被裁）；
- 提示行（spinner + 提示）黄色 `class:await`（bold #ffd75f，与 notice 同色）；
- 动画复用「运行中」spinner 线程：`_modal_animate` 标记；`_spin_loop`
  模态期间原本停重绘（隐藏运行中），现 animate 时持续重绘驱动帧；
  模态关闭时若非 busy 停 spinner；
- 布局变化**仅限 animate 模态**（确认类），/login、/model 等既有模态
  不受影响（回归门禁验证）。

### legacy（`core/prompt_utils.py`）

- 提示前不打印空行（上方不空行）；先写 `\n\n\033[2A`（下移两行再回移）
  使提示行下方留两空行；提交后光标落第一空行、调用方 `print()` 两次
  保留之；
- 动画：prompt 用 callable，后台线程每 0.1s 推帧并 `invalidate()`
  （pt 的 invalidate 线程安全）；spinner/提示黄色（`class:spin/await`）；
- 非 TTY 回退普通提问（不动光标、无动画）。

### 接口（`core/tool_executor.py` / `prompt_utils` / `shell`）

- `_confirm_execution`：选项逐行 print → `ask_text_or_none("选择
  [y/n/all/always]: ", animate=True)` → 提交后 `print()` 两次；
- `prompt_utils.ask_text_or_none(prompt, animate=False)` 新参数；全屏
  钩子 `ask_text_sync(prompt, password, animate)` 透传；
- 帧串懒加载自 `shell._SPIN_FRAMES`（避免两处手写 braille 字面量——
  开发期再次踩 LLM braille 字符幻觉，懒加载彻底绕开）。

## 四、测试

- 新增门禁 `tests/ui/check_confirm_lines.py`（第 32 套件，27 项断言）：
  - 全屏 pty 24×80 + **pyte 列精确重放**：提示行上方不空行（always 紧贴
    模态行）、下方空两行、提示行黄色（SGR `38;5;221` 或 truecolor
    `38;2;255;215;95`，兼容 pt 色深量化）；always 往上依次 all/n/y/标题；
    ≥2 个 braille 动画帧；空行判定**只看主区列 0..77**（第 78 列是
    滚动条 █/│，不算内容）；y 回车→True、第二轮 n 回车→False；
  - legacy 同样 pyte 重放（`\n\n\033[2A` 下方空行技巧含光标回移，
    按字节行序断言会误判）；

    匹配（差分重绘下字节标记不可靠，沿用 check_undo_redo 教训）。
